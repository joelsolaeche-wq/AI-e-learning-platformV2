# Requirements

> v1 scope locked for demo. Demo path: sign up → browse catalog → join cohort → watch video → take quiz → chat with AI tutor.

---

## v1 Requirements

### Authentication (AUTH)

- [ ] **AUTH-01**: User can create an account with email and password
- [ ] **AUTH-02**: User can log in with email and password and stay logged in across sessions
- [ ] **AUTH-03**: User can log out from any page
- [ ] **AUTH-04**: Unauthenticated users are redirected to login when accessing protected routes

### Course Catalog (CATALOG)

- [ ] **CATALOG-01**: User can browse a catalog of available AI courses
- [ ] **CATALOG-02**: User can view a course detail page with description, modules, and cohort schedule

### Cohort & Enrollment (COHORT)

- [ ] **COHORT-01**: User can view available cohorts for a course with start dates
- [ ] **COHORT-02**: User can enroll in a scheduled cohort
- [ ] **COHORT-03**: User has a dashboard showing all enrolled cohorts with progress indicators
- [ ] **COHORT-04**: User can see teammates in their cohort and their progress (cohort social dashboard)

### Lesson Experience (LESSON)

- [ ] **LESSON-01**: User can watch a video lesson with play/pause/seek and playback speed control (0.75x–2x)
- [ ] **LESSON-02**: Video resumes from the last watched position when reopened
- [ ] **LESSON-03**: Lesson is automatically marked complete when user reaches 90% of video duration
- [ ] **LESSON-04**: User can see lesson completion status on the cohort dashboard

### Quiz (QUIZ)

- [ ] **QUIZ-01**: User can take a quiz after completing a lesson
- [ ] **QUIZ-02**: Quiz is scored server-side (quiz definitions never sent to client)
- [ ] **QUIZ-03**: User sees their score and per-question answer review immediately after submission

### AI Tutor (AI)

- [ ] **AI-01**: User can open an AI chat panel during a lesson
- [ ] **AI-02**: AI tutor responses stream in real time (no batch response delays)
- [ ] **AI-03**: AI tutor is grounded in the lesson transcript (answers reference lesson content)
- [ ] **AI-04**: Chat history persists across sessions for the same lesson
- [ ] **AI-05**: AI tutor gracefully declines questions outside course scope

## v2 Requirements (Deferred)

### Auth
- Google OAuth / SSO
- Email verification flow
- Role selection at sign-up (developer / PM / business) — enables role-aware AI

### Lesson
- Closed captions (ADA/WCAG compliance)
- Chapter/timestamp markers on video scrubber
- Weekly lesson unlock based on cohort start date

### AI
- Role-aware AI responses (code example vs. process analogy)
- AI-generated quiz explanations (explains wrong answers with lesson reference)
- Proactive AI nudge on repeated re-watch or quiz failure

### Platform
- Instructor dashboard (create cohorts, track learners, give feedback)
- Coding labs / embedded sandbox
- Cohort peer chat
- Completion certificates
- Admin panel
- Manager progress view

---

## Out of Scope

| Exclusion | Reason |
|-----------|--------|
| Payments / billing | Not part of demo narrative |
| SCORM / xAPI | Enterprise integrations, post-demo |
| Self-paced (non-cohort) learning | Adds UX branches that complicate demo scope |
| Multi-cohort enrollment | Not needed for single-path demo |
| Mobile app | Web-only for demo |
| Live video / synchronous sessions | Async video sufficient |
