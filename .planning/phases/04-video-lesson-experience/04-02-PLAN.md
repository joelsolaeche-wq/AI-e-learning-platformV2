Create `app/api/video/progress/route.ts` as a Next.js Route Handler.

The handler:
1. Validates the request method is POST (implicit via export name `POST`)
2. Parses body: `{ lessonId: string, position: number, duration: number, completed: boolean }`
3. Gets the authenticated user via `createClient()` → returns 401 if not authed
4. Validates enrollment: checks that the user is enrolled in a cohort that contains this lesson
5. Upserts lesson_progress

Enrollment check query:
```sql
-- Find if user is enrolled in any cohort whose course contains this lesson
SELECT 1
FROM enrollments e
JOIN cohorts c ON e.cohort_id = c.id
JOIN modules m ON m.course_id = c.course_id
JOIN lessons l ON l.module_id = m.id
WHERE e.user_id = $user_id
  AND e.status = 'active'
  AND l.id = $lesson_id
LIMIT 1
```

In Supabase JS (multi-step approach since complex joins aren't directly chainable):
1. Get lesson's module_id: `supabase.from('lessons').select('module_id').eq('id', lessonId).single()`
2. Get module's course_id: `supabase.from('modules').select('course_id').eq('id', module_id).single()`
3. Check enrollment: `supabase.from('enrollments').select('id').eq('user_id', uid).eq('status', 'active').in('cohort_id', cohortIds).single()` — where cohortIds comes from `supabase.from('cohorts').select('id').eq('course_id', course_id)`

Simpler: use a single RPC or check via lessons RLS. Since lessons RLS already blocks unenrolled users at the SELECT level, we can validate enrollment by checking if the lesson SELECT returns a row:

Actually simplest correct approach:
1. Get lesson to verify it exists and check user can read it (RLS blocks unenrolled)
2. If lesson select returns error (PGRST116 = no row) → 403

Full implementation:
```ts
import { createClient } from '@/lib/supabase/server'
import { NextResponse } from 'next/server'

export async function POST(request: Request) {
  const supabase = await createClient()

  // Auth check
  const { data: { user } } = await supabase.auth.getUser()
  if (!user) {
    return NextResponse.json({ error: 'Unauthorized' }, { status: 401 })
  }

  // Parse body
  let body: { lessonId?: string; position?: number; duration?: number; completed?: boolean }
  try {
    body = await request.json()
  } catch {
    return NextResponse.json({ error: 'Invalid JSON' }, { status: 400 })
  }

  const { lessonId, position, duration, completed } = body
  if (!lessonId || position === undefined || position === null) {
    return NextResponse.json({ error: 'Missing lessonId or position' }, { status: 400 })
  }

  // Enrollment check — RLS on lessons restricts SELECT to enrolled users.
  // If this query returns no row, the user is not enrolled (or lesson doesn't exist).
  const { data: lesson, error: lessonError } = await supabase
    .from('lessons')
    .select('id, duration_seconds')
    .eq('id', lessonId)
    .maybeSingle()

  if (lessonError || !lesson) {
    return NextResponse.json({ error: 'Forbidden' }, { status: 403 })
  }

  // Determine completion: explicit flag OR 90% threshold
  const effectiveDuration = duration ?? lesson.duration_seconds ?? 0
  const pct = effectiveDuration > 0 ? position / effectiveDuration : 0
  const isCompleted = completed === true || pct >= 0.9

  // Upsert lesson_progress
  const now = new Date().toISOString()
  const upsertData = {
    user_id: user.id,
    lesson_id: lessonId,
    last_position: position,
    completed: isCompleted,
    updated_at: now,
    ...(isCompleted ? { completed_at: now } : {}),
  }

  const { error: upsertError } = await supabase
    .from('lesson_progress')
    .upsert(upsertData, { onConflict: 'user_id,lesson_id' })

  if (upsertError) {
    console.error('lesson_progress upsert error', upsertError)
    return NextResponse.json({ error: 'Internal error' }, { status: 500 })
  }

  return NextResponse.json({ ok: true, completed: isCompleted })
}
```
