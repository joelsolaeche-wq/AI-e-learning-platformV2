## Spacing Scale

Standard 8-point scale. All values are Tailwind utility multiples.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding |
| sm | 8px | Compact element spacing, card inner padding |
| md | 16px | Default element spacing, card body padding |
| lg | 24px | Section padding, card grid gap |
| xl | 32px | Page section breaks, catalog page padding |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level top/bottom padding |

Exceptions: none

---

## Typography

Inter font family throughout. Exactly 4 sizes, 2 weights.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label / Caption | 14px | 400 | 1.4 |
| Subheading | 20px | 600 | 1.3 |
| Heading / Display | 28px | 600 | 1.2 |

Usage in this phase:
- Course card title: 16px semibold (600)
- Course card description: 14px regular (400), 2-line clamp
- Catalog page heading: 28px semibold
- Course detail page heading: 28px semibold
- Module/lesson labels: 14px regular

---

## Color

Dark theme is the only active theme (`forcedTheme="dark"` in layout.tsx). All values reference the `.dark` block from `app/globals.css`.

| Role | OKLCH Value | Hex Approx | Usage |
|------|-------------|------------|-------|
| Dominant (60%) | oklch(0.145 0 0) | #1a1a1a | Page background, outer surfaces |
| Secondary (30%) | oklch(0.205 0 0) | #272727 | Cards, panel backgrounds |
| Muted surface | oklch(0.269 0 0) | #333333 | Hover states, badges, secondary cards |
| Foreground | oklch(0.985 0 0) | #fafafa | Primary text |
| Muted foreground | oklch(0.708 0 0) | #ababab | Secondary text, descriptions, labels |
| Accent (10%) | oklch(0.922 0 0) | #ebebeb | Primary buttons, active nav items, card hover ring |
| Destructive | oklch(0.704 0.191 22.216) | ~#e05a3a | Destructive actions only |
| Border | oklch(1 0 0 / 10%) | white/10% | Card borders, dividers |

Accent reserved for: primary CTA buttons, active navigation indicator, card hover border highlight — **never** used for decorative elements or all interactive elements indiscriminately.

## Visual Hierarchy

| Screen | Primary Focal Point | Secondary | Tertiary |
|--------|--------------------|-----------|---------:|
| /catalog | Course card grid (3-col, fills viewport below header) | Page heading "AI Course Catalog" | Badge tags on cards |
| /catalog/[courseId] | Course title + thumbnail at top of page | Module/lesson outline below | Cohort schedule card at bottom |

Executor priority rule: when in doubt, give the card grid or course title more visual weight than navigation or metadata elements.
