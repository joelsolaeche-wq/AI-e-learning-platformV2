# Plan 02-03: Middleware Update + shadcn Component Installation

> Wave 2 — depends on both Wave 1 plans (02-01 and 02-02) completing. Must run before Wave 3 (02-04, 02-05) since catalog pages depend on badge, separator, and middleware protection.

## Goal

Protect the `/catalog` route in middleware so unauthenticated users are redirected to `/auth/login`. Install the three missing shadcn/ui components (`badge`, `skeleton`, `separator`) that the catalog and course detail pages will import. These are prerequisites for Wave 3.

<threat_model>
| Threat ID | Description | Mitigation |
|-----------|-------------|------------|
| T-2-01 | Unauthenticated access to /catalog | This plan adds '/catalog' to the protectedPaths array in middleware.ts — primary defense layer; catalog Server Components also self-guard with getUser() check |
| T-2-02 | RLS bypass exposing courses to wrong users | Not applicable to middleware/components — RLS enforced at DB layer in 02-01 |
| T-2-03 | Anon access to quiz_definitions.correct_answer | Not applicable to middleware/components |
| T-2-04 | SQL injection via courseId in URL | Not applicable to middleware/components |
| T-2-05 | Seed data FK violations | Not applicable to middleware/components |
</threat_model>

<title>Add /catalog to middleware protectedPaths</title>

<read_first>
- middleware.ts (current file — must read before editing; current protectedPaths is ['/dashboard', '/cohorts', '/lessons', '/admin'])
- .planning/phases/02-data-model-course-catalog/02-RESEARCH.md (Section 9 — "Middleware: add /catalog to protected paths")
- .planning/phases/02-data-model-course-catalog/02-PATTERNS.md (Section 8 — middleware pattern with exact before/after values)
</read_first>

<action>
Edit `middleware.ts` to add `'/catalog'` to the `protectedPaths` array.

**Current line (line 34 in middleware.ts):**
```ts
const protectedPaths = ['/dashboard', '/cohorts', '/lessons', '/admin']
```

**Replace with:**
```ts
const protectedPaths = ['/dashboard', '/cohorts', '/lessons', '/admin', '/catalog']
```

This is the only change to `middleware.ts`. The rest of the file stays identical. No other logic needs updating.

The effect: any request to `/catalog` or `/catalog/[courseId]` (since the middleware uses `pathname.startsWith(p)`) where the user is not authenticated will redirect to:
```
/auth/login?redirectTo=/catalog
```
or
```
/auth/login?redirectTo=/catalog/00000000-0000-0000-0000-000000000010
```
respectively.
</action>

- `middleware.ts` does NOT contain the old array `['/dashboard', '/cohorts', '/lessons', '/admin']` without `/catalog`
- `npm run build` exits 0 after this change
- Manual test: sign out → navigate to http://localhost:3000/catalog → browser URL changes to http://localhost:3000/auth/login?redirectTo=%2Fcatalog (or /auth/login?redirectTo=/catalog)
</acceptance_criteria>
</task>

</read_first>

<action>
Run the following command from the project root to install all three missing shadcn/ui components at once:

```bash
npx shadcn add badge skeleton separator
```

This command:
1. Reads `components.json` to determine the install location and style preset
2. Downloads `badge`, `skeleton`, and `separator` from the shadcn/ui registry
3. Creates or updates the following files:
   - `components/ui/badge.tsx`
   - `components/ui/skeleton.tsx`
   - `components/ui/separator.tsx`
4. Installs any missing peer dependencies (e.g., `@radix-ui/react-separator` for separator)

**If the CLI prompts for confirmation (overwrite existing files, etc.):**
- Answer "y" to all prompts to proceed with installation
- If `badge` or `skeleton` already exist, overwriting is safe — they are generated files

**Expected output after each component installation:**
```
✓ Installing badge...
✓ Installing skeleton...
✓ Installing separator...
```

**Alternative — install one at a time if the combined command fails:**
```bash
npx shadcn add badge
npx shadcn add skeleton
npx shadcn add separator
```

**Do NOT manually create these files.** Always use the shadcn CLI — it installs peer dependencies and follows the project's `components.json` style preset (base-nova).
</action>
