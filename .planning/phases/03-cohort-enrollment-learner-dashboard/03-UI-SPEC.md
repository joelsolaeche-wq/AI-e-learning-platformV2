## Typography

Inter font. All sizes are px-equivalent Tailwind classes.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Display | 24px (`text-2xl`) | 600 (`font-semibold`) | 1.2 | Page heading "Your Cohorts" |

## Color

Dark mode only (forced). All values are OKLCH CSS custom properties from `app/globals.css`.

| Role | CSS Token | OKLCH Value | Usage |
|------|-----------|-------------|-------|
| Dominant (60%) | `--background` | `oklch(0.145 0 0)` | Page background |
| Secondary (30%) | `--card` | `oklch(0.205 0 0)` | Cohort cards, inner surfaces |
| Muted surfaces | `--muted` | `oklch(0.269 0 0)` | Teammate rows, progress track background |
| Primary text | `--foreground` | `oklch(0.985 0 0)` | Headings, primary labels |
| Muted text | `--muted-foreground` | `oklch(0.708 0 0)` | Secondary text, completion percentages |
| Border | `--border` | `oklch(1 0 0 / 10%)` | Card borders, dividers |
| Destructive | `--destructive` | `oklch(0.704 0.191 22.216)` | Destructive actions (not used in Phase 3) |

> **No hue-based accent.** The design system is fully neutral/grayscale. The only high-contrast element is `--primary` (`oklch(0.922 0 0)`) used for the primary button (Join Cohort). Do not introduce custom accent colors — all interactive elements use the token system.

Accent reserved for: primary CTA button (`<Button>` default variant) — the "Join Cohort" action only. All other interactive elements use `ghost`, `outline`, or `link` variants.

**Source:** `app/globals.css` dark mode tokens.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | "Join Cohort" |
| Already-enrolled state | "Enrolled" (badge, disabled — replaces button per D-03) |
| Dashboard link | "Go to Course →" |
| Progress label | "0 of 3 lessons complete" (word form, not raw %) |
| Empty state heading | "No cohorts yet" |
| Empty state body | "Browse the catalog to find your team's AI course." |
| Empty state CTA | "Browse catalog →" (link to `/catalog`) |
| Error state (enrollment failure) | Toast: "Couldn't enroll — try again" (auto-dismiss, non-blocking) |
| Teammate row format | "{display_name} · {N}%" (e.g. "Jane · 33%") |
| Progress bar aria-label | "Lesson progress: {N} of {total} complete" |

**Sources:** CONTEXT.md D-03, D-05, D-06, D-07; user input (empty state, error state).

## Interaction Patterns

| Interaction | Pattern |
|-------------|---------|
| Enroll action | Server Action with `redirect('/dashboard')` on success — no optimistic UI (D-02) |
| Enrollment error | Toast notification (auto-dismiss ~4s). Button remains clickable for retry. |
| Progress bar | CSS `width: {pct}%` on a `bg-muted` track. `bg-primary` fill. `h-1.5` (6px). |
| Teammate progress bar | Same pattern, smaller: `h-1` (4px). Inline within teammate row. |
| Dashboard loading | `<Skeleton>` placeholders for card content during data fetch |
| Already enrolled | "Join Cohort" button replaced with `<Badge variant="secondary">Enrolled</Badge>` |

## Visual Hierarchy

| Screen | Primary Focal Point | Secondary |
|--------|--------------------|-----------||
| Course detail page | "Join Cohort" button (default variant, high contrast) | Cohort card with start date |
| Learner dashboard | Cohort card(s) with progress bar | Teammate roster within card |
| Dashboard empty state | "Browse catalog →" CTA link | Empty state heading |

Reading order: Card heading → Status badge → Progress bar → Teammate rows → "Go to Course →" link.

## Layout Contract

| Area | Specification |
|------|---------------|
| Dashboard page | Full-width single column (no sidebar for Phase 3) |
| Cohort card | Full card width, stacked vertically per D-04 |
| Card header | Title (Heading) + status Badge, horizontal, space-between |
| Progress section | Label row ("0 of 3 lessons complete") + progress bar below |
| Teammate section | Stacked rows inside card body, `gap-sm` (8px) between rows |
| Teammate row | `{name}` (Body) · `{pct}%` (Label/muted) — inline, space-between |
| Empty state | Centered, `gap-md` stack: heading + body + link |
